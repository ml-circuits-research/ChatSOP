# Audit the complete agent experiment

Citește `09-evaluare.md` și `12-stadiu.md`. Separă rezultate runtime, backend, memorie și neuronale. Rulează tool-urile existente și păstrează ieșirea brută. Backend lipsă înseamnă test sărit, nu trecut.

Construiește dialoguri RO independente: informație nouă, întrebare, explicație, corecție, trecut, lipsă de date și ambiguitate. Verifică izolarea utilizatorilor. Compară forma SOP cu sensul mesajului și CNL cu textul reformulat.

Raportează acuratețea pe categorii, abțineri, erori, cost total de memorie și latențe. Pentru claims de superioritate adaugă modele mari cu acces comparabil la tools și memorie. Nu generaliza din seed-ul cu aceleași șabloane la conversație liberă.
