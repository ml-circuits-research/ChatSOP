# Dependency record

ChatSOP's local symbolic CLI requires Node.js >=22.13 and its built-in modules, including `node:sqlite`; the root `package.json` declares no third-party npm packages. ML training, optional external solvers, and CPU model serving have separate prerequisite checks. Neither an existing command nor a configured model proves a dependency is installed or licensed for redistribution. All exact upstream revisions, resolved transitive dependency lists, and license obligations for downloaded models and external packages must be recorded before distributing their artifacts. This file records declared requirements and unresolved facts; it does not authorize installation.

## Dictionary data (bilingual dictionary of the edges)

Since the owner decision of 2026-10-01 (English-only core) the product linking path reads only the English synonym view of this data (`englishDictionary()`); the Romanian columns and the Wiktionary data serve language identification (LanguagesUtil), the gloss backend of TranslatorService and the archived evaluations.

`sop/dictionary.mjs` and its maintenance CLI `probably_obsolete/tinyLLMExperiments/tools/dictionary.mjs` are plain Node code with no package dependency: the sources are tab-separated text files in `config/dictionary/`, parsed and compiled by about two hundred lines of local code into lookup maps cached under `state/cache/dictionary/` (keyed by the SHA-256 of the sources). A dictionary or NLP package would add an opaque lexicon and inflection model; the host needs only exact lookups over reviewable data, so none is used.

| Source (priority) | Origin | Licence and obligations |
| --- | --- | --- |
| `manual.tsv` (10) | Hand-authored, reviewed entries: prepositions, copula and auxiliaries, everyday verbs, nouns, adjectives, weekdays and numbers; entries approved from `review.tsv` | MIT (repository LICENSE); original text |
| `generator.tsv` (20) | `node probably_obsolete/tinyLLMExperiments/tools/dictionary.mjs seed-generator` from the DS015 generator lexicon (`tools/datasets/diversity/`) | MIT (repository LICENSE); original text |
| `wiktionary.tsv` (30) | `node probably_obsolete/tinyLLMExperiments/tools/dictionary.mjs import-wiktionary` from the Romanian section of English Wiktionary via kaikki.org/wiktextract, downloaded on 2026-09-29 into the git-ignored `datasets_sources/wiktionary-ro/` (URL, bytes and sha256 in its `provenance.json`) | CC BY-SA 4.0 and GFDL, English Wiktionary contributors. The exported file keeps the ShareAlike licence, the attribution and a modification notice in its header; see DS011 |

Nothing was installed. Removal: delete `config/dictionary/wiktionary.tsv` (the dictionary still loads from the other sources) or the whole `config/dictionary/` directory together with its callers.

The frame and synonym list (`sop/frames.mjs`, owner answer to Q-SYM-2) is local code too. Its data are `config/dictionary/frames-world.tsv` and `frames-train.tsv` (MIT, derived from the training world and training golds) and `frames-wordnet.tsv`, derived by `node probably_obsolete/tinyLLMExperiments/tools/frames.mjs build` from Princeton WordNet 3.0 downloaded on 2026-09-29 into the git-ignored `datasets_sources/wordnet-3.0/` (URL, bytes and sha256 in its `provenance.json`; WordNet 3.0 licence, notice kept in the exported file; DS011). No WordNet package or reader library is used: the build parses `index.verb` and `data.verb` directly. Removal: delete `frames-wordnet.tsv` and its manifest entry (the list still loads from the other files).


## Frozen branch (tiny-model experiments)

Since the owner decision of 2026-10-01 the following are not dependencies of the product: Stanza and the Python UD worker, the Python ML packages (torch, transformers, peft, accelerate, huggingface_hub, safetensors, sentencepiece), `llama.cpp` and GGUF serving, the rootless Podman CUDA training image, the translator and proofing models, LanguageTool, and the spelling, translation and semantic-similarity resources. Their records, versions and licence notes are kept verbatim in `probably_obsolete/tinyLLMExperiments/dependencies.md`. The dictionary data above stays only for its English synonym view and the reviewed entries; the Romanian columns and the Wiktionary data belong to the frozen branch.
