# Dependency record

ChatSOP's local symbolic CLI requires Node.js >=22.13 and its built-in modules, including `node:sqlite`; the root `package.json` declares no third-party npm packages. ML training, optional external solvers, and CPU model serving have separate prerequisite checks. Neither an existing command nor a configured model proves a dependency is installed or licensed for redistribution. All exact upstream revisions, resolved transitive dependency lists, and license obligations for downloaded models and external packages must be recorded before distributing their artifacts. This file records declared requirements and unresolved facts; it does not authorize installation.

## Python ML packages

The optional `training/python/requirements.txt` lists ranges; the image-specific `training/container/requirements.lock` records exact versions modeled on an observed native installation, not hash-pinned wheels or fully reproducible upstream indexes. Each is training/inference-scoped, not an npm dependency. Installation belongs to the explicit reviewed image build or a reviewed ML environment, never symbolic CLI startup. Python remains justified by tokenizer/model APIs, autograd, adapters, model file loading and export. Transitive binary licenses and notices still require review before distribution; do not treat a package import as GPU qualification.

The selected training command checks only the dependencies it uses. Package/version and revision records must travel with each run. `models/<model>/bases/<revision>/` denotes separately downloaded base weights and `models/<model>/<run>/<role>/` denotes per-run artifacts: the model's own license, provenance, revision and redistribution rights must be checked before download or publication. The repo's software license does not cover third-party datasets or weights. For training prerequisites and observed limitations see `docs/specs/DS007-training.md`; for dataset rights see `docs/specs/DS008-data-evaluation.md`.

`config/train-qwen.json` pins the optional `Qwen/Qwen3-0.6B` base to Hugging Face revision `c1899de289a04d12100db370d81485cdf75e47ca`; its [LICENSE at that revision](https://huggingface.co/Qwen/Qwen3-0.6B/raw/c1899de289a04d12100db370d81485cdf75e47ca/LICENSE) states Apache License 2.0, Copyright 2024 Alibaba Cloud. Preserve that license and required attribution/notice obligations if weights are acquired or redistributed; no weights are included or qualified by this record. The configured Gemma base has unresolved revision-specific license and redistribution obligations. `datasets_sources/catalog.json` (root-level raw source cache, separate from `datasets/`) lists prospective QA2D and ProofWriter inputs; QA2D card-level MIT does not resolve the rights of constituent sources, and ProofWriter upstream rights require verification. No external corpus is included merely by listing it.

The pinned Qwen base was subsequently downloaded on this host into its separate `models/qwen/bases/<revision>/` directory. A tokenizer-only query-corpus audit loaded no model weights and observed no over-length rows; this is not model inference, fine-tuning, or training authorization. Gemma was not acquired as a substitute with presumed rights.
