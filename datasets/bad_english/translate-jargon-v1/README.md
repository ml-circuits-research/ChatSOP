# translate-jargon-v1

Romanian and mixed Romanian-English messages with diverse jargon, paired with an English translation that keeps every jargon term, code token, name, number and quote exactly. It trains and tests a CPU-fast translator (study `translate-distill-v1`, owner approval of 2026-10-01): can a small Marian model learn WHERE the jargon is and leave it alone?

- `train.jsonl`, `dev.jsonl`: rows `{id, source, target, terms, clean, domain, style, length, writer, target_source, source_license, split}`. `terms` are the jargon terms the writer was told to include (they must appear verbatim in `target`); `clean: true` rows have no jargon (plain Romanian, so the model does not learn to over-preserve). Dev rows with `heldout_terms: true` contain a term (160 terms in all) that never occurs in train, to separate "learned the idea" from "memorised the term".
- Not a sealed test: the evaluation set is `datasets/natural/messages.jsonl` (the owner's own messages), which is never trained on.
- Sources (DS014 "Jargon term sources for translate-jargon-v1", `datasets/SOURCES.md`): jargon inventories for 42 domains and the source messages are written by Grok (`xai-oauth/grok-4.20-0309-non-reasoning`) and GLM (`zai/glm-5.3-flash`), the targets by DeepSeek flash; OPUS KDE4, GNOME, Ubuntu, EMEA and JRC-Acquis (en-ro) are local statistics only, no sentence of them is used (8-gram check `tools/datasets/translate-jargon/nocopy.mjs`: 0 hits).
- The ChatSOP project's own jargon is excluded: `tools/datasets/translate-jargon/blocklist.mjs` (only the project's own vocabulary: project and component names, wire/circuit in English and Romanian forms, dataset names, sigilat, plus identifier-like tokens such as file names and paths from the owner's messages; ordinary words such as review, docs or test are not jargon and are not blocked, owner decision 2026-10-01) drops any row whose source, target or terms contain a blocked term; rows with a content-word overlap of 0.5 or more with a natural sentence are dropped too. `tools/datasets/translate-jargon/verify.mjs` re-checks all of this and fails closed.
- Rebuild: `node tools/datasets/translate-jargon/build.mjs terms|collect-terms|messages|collect-messages|targets|assemble` (omp folders `datasets_sources/tj_*`, fenced), then `nocopy.mjs`, `verify.mjs`.
- Review status: `not_reviewed` (LLM-written targets, mechanical checks only). Training is allowed only under the owner approval recorded in the journal (2026-10-01) for one run plus one corrective rerun.
