### Legacy RecallSOP and H7 reasoning boundary (2026-09)

**Implemented — specialized reasoning, not associative truth.** The host linker expands a goal through approved rule heads, retrieves admitted facts under time and budget limits, and supplies a reduced problem to the chosen reasoner; Holo/Weaver correlations do not add a fact or rule by themselves. The JS registry implements bounded deduction, abduction of *ground* missing facts, diagnostic ranking by pair separation (not calibrated information gain), induction of candidate patterns from supplied traces with separately checked holdout IDs, structural analogies, planning and what-if simulation. Induced patterns require reviewed semantic validation before rule promotion; explanations, suggested tests, transferred conclusions and plans remain conditional candidates. Explicit causal rules are required for counterfactual mode, and the simulated world does not modify source memory (`reasoning/linker.mjs:24-58`; `reasoning/registry.mjs:14-19,30-52`; `reasoning/abduction.mjs:12-46`; `reasoning/learning.mjs:39-63`; `reasoning/worlds.mjs:8-43`; `docs/wire_typs/abduce.html:4-25`; `docs/wire_typs/induce.html:4-37`).

**Implemented — constrained backend split.** `reference` stays on bounded JS; `advanced` can choose SWI for suitable relational work and Z3 for suitable numeric work, while other registered modes use the shared JS controller. A required numeric constraint cannot be silently discarded on a relational route, and a missing optional backend is not evidence that it ran. An absent retained fact remains unknown rather than false; only admitted observations and approved rules can establish ordinary support. A hypothetical assumption is conditional context, never a sourced repository fact or implicit `remember` write (`reasoning/registry.mjs:14-19,30-52`; `reasoning/reasoner.mjs:72-94`; `docs/wire_typs/reason.html:4-12`; `docs/wire_typs/remember.html:2-14`; `probably_obsolete/references/H7.docx:129-135`).

**Rejected — outdated wire and model-authoring suggestions.** The older proposal's model-authored `fact`/`event`/`action`/`hypothesis`/`procedure`, execution `recall`/`reason`/`assert`, and parenthesized atoms are not this session's model-facing contract. A small model emits only `stated`, `assumed`, `unclear`, `query`, or `constraint`, written as context-free strings; the approved host compiles `resolve`, `pack`, `solve`, `cnl`, `remember` and, when genuinely required, `clarify` with `pendingSop`/`required`/`next`. Missing evidence alone is `unknown`; `constraint.select` asks for a checked scalar and ambiguity requires clarification even if a claim is entailed (`docs/wire_typs/small-model.html:3-17`; `docs/wire_typs/remember.html:2-14`; `probably_obsolete/references/RecallSOP-proposal.docx:125-184,253-277`).
