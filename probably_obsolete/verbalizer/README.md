# Verbalizer (archived 2026-10-01)

The LLM verbalizer (a small model rewriting the controlled-language answer into natural prose) was never trained: only a dry-run
log exists (`eval/reports/history/verbalizer-dry-run.log`). The chat and the CLI answer with the deterministic CNL text of the
host. The smoke evaluation script, its test and the prompt are kept here as evidence (hygiene cleanup H4, journal 2026-10-01);
their import paths (`../server/llm.mjs`) are no longer valid.
