jsEval

Evaluates a restricted JavaScript-shaped expression for controlled coding-agent composition. This is not a JavaScript script runner, and it cannot read files, call the network or execute arbitrary functions.

Status and author: Host-controlled coding-agent/system surface, not a small-formalizer training target. jsEval is always available to trusted and host circuits; there is no host policy switch for it. It is impossible for the small model: model-surface admission rejects jsEval (MODEL_TYPES in sop/declarative.mjs). The expression sandbox limits maxExprOps and maxExprBytes still apply.

Accepted fields

Single means at most once, repeatable means zero or more, and required means at least once at parse time. Other field names are rejected.

FieldCardinalityAccepted values and current behavior
exprAt most once; requiredRestricted JavaScript-like expression, e.g. only($rows).name; interpreter reads completed $id values and rejects unavailable globals/statements.

Execution and result

Allowed literals are double-quoted JSON strings, finite numbers, booleans, null, arrays, and object literals with safe keys. Operators: unary !/-, + - * / %, comparisons < <= > >= for same-type numbers/strings, strict-equivalent == === != !==, short-circuit && || ??, and ?:. Numeric arithmetic requires numbers; string + joins strings. Dot/bracket lookups require own properties (or length for arrays/strings). Calls: String(x), Number(x), only(array) for exactly one element; numeric Math.abs/min/max/floor/ceil/round; string trim/toLowerCase/toUpperCase/normalize/slice/substring/includes/startsWith/endsWith/replaceAll/split, and array slice/join. Methods enforce argument types; no callbacks or regular expressions.

eval, Function, imports, globals, arbitrary object methods and keys __proto__, prototype, constructor, caller, callee, arguments are forbidden. Limits: source 16,384 characters, 4,096 tokens, 2,048 AST nodes, depth 64, at most 32 call arguments, default 10,000 evaluated operations, 65,536 bytes serialized output/string budget, and 4,096 array items. Host policy may lower operation/output budgets. Nonfinite results fail. The produced value is ordinary data without proof or world write. No small-model training using this wire is planned.

Current SOP examples

Numeric composition

@start value
  data 770

@travel value
  data 70

@arrival jsEval
  expr $start + $travel

The interpreted result is 840. This expression has no side effect.

Safe object projection and unique selection

@rows value
  data [{name:"Ana", score:4}]

@selected jsEval
  expr only($rows).name.toUpperCase()

The result is the string ANA. With zero or two elements, only fails instead of choosing a row.

Invalid or unsafe example

@unsafe jsEval
  expr process.env.SECRET

Although this text parses as a property lookup, process is an unavailable global at evaluation; no host access is granted. A JavaScript statement or arrow function is rejected by the expression parser.

Where jsEval sits in the knowledge language

jsEval is a trusted, host-only escape hatch for what the core condition leaves cannot express (string handling, calendar arithmetic, a lookup the host owns). It is not a knowledge wire and not in the grammar of the knowledge language (the manual). The logic engines (Prolog, Z3, Datalog, ASP, SQL) cannot see inside an expression, so a rule or aggregate whose truth depends on one is not_expressible for them unless the host exposes it as a provider that feeds facts back; the oracle may evaluate it in-process. A coding agent that compiles a source never writes jsEval: an expression is code, its effects cannot be read off the wire and no engine can check it, so one that arrives from a source is not accepted into memory; a reviewed host step may admit one, stored with its source sentence and version like any governed wire. Arithmetic of manuals (totals, thresholds, tariffs, durations) is written with compute, compare, the aggregate wire and constraint; what they cannot express (rounding rules, percentages with fractions, date arithmetic, string operations) is reported as "not expressed".
