premise

A premise is a conditional assumption authored by a small conversational model. It carries no source, quote, memory-write or proof-of-truth field. The host retains original user input and model-interpretation provenance separately. A premise can remain available as conditional context across turns and be supplied as a temporary solve assumption; it is never implicitly recorded as an observed repository fact. A trusted fact and explicit authorized remember are distinct general-runtime operations.

A premise-only model turn returns a host CNL packet with status: context_updated and the number of conditional premises recorded in the conversational context. It does not create repository claim IDs, perform a session write or publish knowledge.

Conditional context and question

@context premise
  holds on_shelf book_a shelf_north

@question query
  where on_shelf book_a shelf_north

The question asks whether the assumed relation follows in the selected context; only conditional support is available from this premise. Neither declaration records the book's actual location. The host expands execution using approved operations and renders a checked result.

Invalid model request

@bad premise
  holds on_shelf ?book shelf_north
  source "catalog card"

A premise has no source field, and ?book is not a ground item. A missing book belongs in query.where, not a guessed assumption. Model-authored input cannot contain remember or claim that this premise was observed.
