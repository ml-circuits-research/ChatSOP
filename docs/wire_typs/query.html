query

A query defines conditions and requested results, not evidence and not an answer. It is one of the four allowed model-authored declarative types. where describes the relation to match; select names the variables to return. solve subsequently evaluates it using explicitly supplied local data or a selected memory view.

Every accepted keyword

KeywordCardinality / defaultAccepted value and concrete effect
whereRepeatable; at least one required[not ]predicate term1 ... (1–4 terms), or nested all/any/end block of atom leaves. Repeated lines are conjunctions; alternatives in any are disjunctions. Variables in a query are matched, not asserted.
selectAt most once; default emptyWhitespace-separated ?name variables bound in every relevant alternative; defines selected columns, not an output wire by itself.
modeAt most once; default select when select is present, otherwise existsselect, exists, count or explain; chooses projected matches, existence, distinct-binding count, or explanation. Select mode requires a selected variable.
filterRepeatable; default noneRestricted Boolean comparison such as ?quantity > 0, or all/any/end expression block. Filters matched values; every referenced variable must be guaranteed bound by where.
atAt most once; default runtime now; exclusive with duringISO date/UTC instant (or beginning/open accepted by instant parser); a whole-field $value can supply an instant. Selects valid-time instant.
duringAt most once; exclusive with attimeless or ISO/UTC START END interval, inclusive/exclusive; selects overlapping valid-time window, not necessarily complete-window support.
asofAt most once; default runtime nowISO/UTC knowledge cutoff or whole-field $value instant; limits repository history visible to retrieval.
limitAt most once; default 100Safe integer 1–10,000; caps returned answers. Truncation means result is incomplete.

Which books are on the north shelf?

Two local catalog claims are grouped only because solve.data takes one value. The query asks about shelf_north, so shelf_south does not match; solving evaluates this question without recording either fact in a session.

@north fact
  holds on_shelf book_a shelf_north
  valid timeless

@south fact
  holds on_shelf book_b shelf_south
  valid timeless

@catalog pack
  items $north $south

@question query
  where on_shelf ?book shelf_north
  select ?book

@answer solve
  query $question
  data $catalog
  output ?book many

A complete answer can bind $book to ["book_a"]; many requests a collection, not independent truth certification. The following asks a different question: how many distinct shelf bindings match?

@north fact
  holds on_shelf book_a shelf_north
  valid timeless

@other fact
  holds on_shelf book_c shelf_north
  valid timeless

@books pack
  items $north $other

@count query
  where on_shelf ?book shelf_north
  mode count

@total solve
  query $count
  data $books
  output ?number count

The count port ?number names a result, not a variable from the query; with both facts admitted, the count is two.

Invalid: unbound output variable

@bad query
  where on_shelf ?book shelf_north
  select ?building

This atom parses, but lowering cannot select a variable not bound by where. See Boolean conditions for supported alternatives.
