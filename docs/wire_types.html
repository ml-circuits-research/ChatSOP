Wire help overview

Model-authored statements, assumptions and questions state intent; host-approved metaprograms build inspectable execution circuits. Variables such as ?xx and ?yy describe unknowns whose matches stay together: one assignment can be a structure, and several can be an array of structures. The actual shape depends on the wire, output mode, and engine. Matching intuition and engine responsibilities.
