# DS018 — Source rights and redistribution evidence

This specification records what has actually been verified about the rights of each external corpus candidate, so that a dataset claim is never derived from a software license. A public repository, a mirror, or an "open" label is not evidence of a data grant. Every row below states the evidence inspected and the resulting status. Where only secondary evidence exists, the status is `unverified`, and the asset stays in quarantine.

Applies to: `tools/datasets/import-*.mjs`, `tools/datasets/converters/**`, `datasets/knowledge/source/**`, any evaluation or training corpus, and any published artifact. The synthetic corpora authored in this repository (`datasets/seed`, `datasets/query-v1`, `datasets/pilot-v1`, `datasets/generated`) are generated by this project and are not affected.

## Status vocabulary

| Status | Meaning |
| --- | --- |
| `cleared` | A primary license notice was read; attribution/modification duties are recorded and satisfied by the artifacts that use it. |
| `permissive-attribution` | The primary notice grants free use and asks for acknowledgement; no ShareAlike obligation was found in that notice. Upstream third-party content still needs its own notice. |
| `unverified` | No authoritative license notice could be located; secondary summaries disagree. Redistribution and gold export are prohibited until evidence is recorded. |
| `restricted` | The publisher's terms limit use (for example to research/non-commercial); not usable for training or redistribution without written permission. |

## Rules enforced here

1. A row with status `unverified` or `restricted` MUST NOT appear in any corpus export, gold target, or published artifact. Only `cleared` and `permissive-attribution` assets may be ingested, with the recorded attribution and modification notices.
2. A software licence never implies a data licence, and a dataset licence never implies rights in the underlying third-party text.
3. The Romanian corpus follows the same rule: synthetic generation, or a source whose rights are recorded here first. Translation into Romanian creates a derivative and therefore inherits the source duties.
4. Training remains unauthorized regardless of this table; a rights-cleared corpus is necessary but not sufficient for the training gate.
5. This specification is an engineering record of verified notices, not legal advice. Where a row is load-bearing for a release, obtain written confirmation from the publisher first.
