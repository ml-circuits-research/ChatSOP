## Real open questions (no inferred answers)

1. What measured task, metadata-inclusive memory ceiling and false-accepted-premise threshold should determine whether H7's still-unimplemented partial-cue, two-plane architecture is worth pursuing? The old paper explicitly proposed these experiments (`probably_obsolete/references/H7.docx:192-205`); current adapters disclose unbounded metadata and missing cue discovery (`memory/banks/holo.mjs:79-83`; `memory/banks/holo-wire.mjs:1-4`).
2. Is an archival store for original pre-semantic text traces and source documents desired, and which authorization/rights policy would allow their ingestion? The old proposal calls for retaining them (`probably_obsolete/references/RecallSOP-proposal.docx:31-45,278-282`), but current hybrid and `associate` only establish the narrower fact/case roles (`memory/banks/hybrid.mjs:9-25`; `docs/wire_typs/associate.html:4-35`). No implementation or dataset permission follows from the proposal.
3. Should the historical H7 five-seed table be retained strictly as a historical citation or separately rerun with matched implementation, seeds, acceptance thresholds and total-byte accounting? Current bench explicitly disavows reproduction (`probably_obsolete/references/H7.docx:151-164`; `tools/bench-h7.mjs:1-22`; `tools/bench-memory.mjs:54-59`).
