# Review epistemic objects and reasoning contracts

Citește capitolele 23–29 și catalogul din sop/contracts. Verifică separat sintaxa, denotația și autoritatea. O ipoteză coerentă nu este confirmată, un pattern frecvent nu este regulă universală, un plan nu este eveniment executat. Revizuiește abducția, negația, temporalitatea, ipotezele de lume închisă și limitele de căutare.

Pentru o regulă propusă, păstrează sursa și contraexemplele. O regulă causal necesită justificare cauzală explicită; temporalitatea/co-apariția nu ajunge. Pentru o acțiune, verifică precondiții, efecte, variabile legate și cost nenegativ. Nu publica reguli sau politici din conversație fără aprobarea cerută de host.

Livrează fișierul SOP revizuit, motivele admiterii/respingerii, exemple pozitive/negative și testul executabil. Rulează suitele de regresie și compară pe profilele comune. Nu transforma skip-ul Prolog/Z3 în rezultat trecut.
